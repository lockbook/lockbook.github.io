Open formats

Files you could still read if we disappeared.

Notes are Markdown.

Plain text with formatting: headings, lists, checkboxes, tables, links. A note you write here is a file any text editor can open, and every Markdown app can too, so nothing about it depends on Lockbook.

Also works in Slack, Discord, Reddit, GitHub, ChatGPT, Google Docs, Notion, Obsidian.

Drawings are SVG.

Your sketches are saved as SVG, the standard vector format the web uses for graphics. Every stroke stays editable, nothing turns blurry when you zoom, and the file opens in design apps and browsers alike.

Also opens in Figma, Illustrator, Canva, PowerPoint, Keynote, Inkscape, Preview, any browser.

Folders are folders.

Export writes your notebook to disk exactly like this — folders you named, Markdown and SVG inside. No manifest, no database, nothing to reconstruct.

Back it up with anything: Time Machine, a USB stick, Dropbox, git.

Your home for everything.

Photos, scans, PDFs, spreadsheets, code: keep them beside the notes they belong with. Lockbook encrypts them like everything else and opens images, PDFs and code right in the app, with more formats on the way. They stay ordinary files, so they come back out exactly as they went in.

Opens in the app today: PNG, JPEG, PDF, code. More coming soon.

Encryption

We built a notebook we can’t read.

Your keys are generated on your device and never leave it. Everything is encrypted before it syncs, so what reaches our servers is noise. Your notes live on your device first, so offline isn’t a mode — it’s the default. Sharing hands a key to a person you name — never to us.

Developers

Scriptable all the way down.

Find notes with fzf, schedule backups with cron, pipe a note into anything — or run lockbook fs and mount the whole notebook as a drive. When the shell is not enough, link the same Rust library the apps are built on, or use one of the SDKs available for many other languages.
